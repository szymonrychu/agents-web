- 2026-11-01 claude-usage-monitor D2 (web-preset-quota): the preset form has a "Usage quota" block after "Autoclose after seconds" with two number fields, "5-hour quota percent" and "Weekly quota percent" (form values `quotaFiveHour`/`quotaSevenDay`, set keys of the same names). - 2026-11-01 claude-usage-monitor D4 (web-usage-history): the Usage page gets a lazy `UsageHistory` (range 24h/7d/30d, default 7d, history `max_points=500` plus sessions for the range, `usePoll(..., 60_000, [range])`) under the cards: a `@mui/x-charts` `LineChart` (`UsageChart`) and a session lane (`SessionTimeline`). `@mui/x-charts` is pinned `~9.16.0` (MIT community package, peers match `@mui/material` 9; 9.17.0 was two days old); no premium package. `@mui/system` was already installed through `@mui/material`, so `npm install` added only x-charts and its own dependencies (d3, vendor, internals). The community package has no range-bar series, so the lane is a plain SVG that shares `from`/`to` and `chartLayout` with the chart: the plot starts at `MARGIN.left + Y_AXIS_WIDTH` (x-charts puts the plot at margin plus the y axis width, default 45), the chart sets `yAxis.width = Y_AXIS_WIDTH` and the lane pads itself by `PLOT_LEFT` and `MARGIN.right`; tests pin both to the constants. Quota reference lines come from `meta.usage.quota_default_pct` and the presets' sparse `spec.usage_quota` (they are per preset, agents-usage does not serve them); a load failure just drops the lines. A line is keyed by (window, value) and labelled "5-hour quota: a, b" / "Weekly quota: c" so equal values in the two windows stay distinguishable; a preset value equal to the default adds no line; at most 6 lines. The window names ("5-hour", "Weekly") and the preset quota field labels live in `usage/quotaLabels.ts`, shared by the form, the series and the quota lines. x-charts takes one x array for all series, so the two windows are aligned on the union of their timestamps with nulls and `connectNulls: true` (with false, two windows sampled at different instants would be all gaps); the cost is that a long outage is bridged by a straight segment. A series with one point shows a mark (a one-point path draws nothing). Origin bar colours are `TOKENS`/`terminalTheme` hues (info, cyan, green, attention, warning, textSecondary), not palette paths, because this theme's `info`, `success` and `secondary` are all grey. The chart chunk is lazy (`React.lazy` in `UsagePage`), so it is a separate Vite chunk.
